# v6.24.0 — accessibility and small fixes

- **Reduced motion:** when your device asks for reduced motion, the card stops its decorative
  animations, opens panels without sliding, crossfades between rooms and turns off the parallax
  tilt.
- **Panels** are announced as modal dialogs to screen readers, and closing one puts keyboard focus
  back where you opened it.
- **Find untagged devices** no longer lists entities a section already shows through its own
  embedded card.

No configuration changes. Details: [CHANGELOG.md](../../CHANGELOG.md).
