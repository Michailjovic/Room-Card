# Release notes archive

Per-version notes, moved here from the repo root in v5.10.1 (54 files were
crowding the root and made the handful of documents people actually need —
README, LAYOUT, PRESETS, ROADMAP — hard to spot).

[`CHANGELOG.md`](../../CHANGELOG.md) in the root is the canonical, complete
history and is what you want in almost every case. These files are the
longer-form notes published alongside each GitHub release, kept for reference.

Moved with `git mv`, so `git log --follow docs/releases/RELEASE_NOTES_vX.Y.Z.md`
still shows the full history of any individual file.
