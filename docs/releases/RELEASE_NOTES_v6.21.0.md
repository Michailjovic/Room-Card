# v6.21.0 — editor polish

- An invalid or duplicate **element ID** can now be fixed with one click (*Use "roleta_bedroom"*).
  Section and group IDs only get the message, because other settings refer to them.
- The **Electricity** section recipe is disabled (with a note) when `electricity-panel-card` isn't
  installed, instead of creating a section that shows a "not registered" error.
- The card's **preview in the card picker** — and a freshly added card — shows a small room sketch
  at 16:9 instead of an empty card.

No configuration changes. Details: [CHANGELOG.md](../../CHANGELOG.md).
