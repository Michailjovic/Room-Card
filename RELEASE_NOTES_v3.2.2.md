# v3.2.2 — HACS license fix + editor readability

**Fixed — HACS validation.** The repository was missing a `LICENSE` file, so HACS' *Validation license* check failed. Added the MIT `LICENSE` file (the licence was already declared in `package.json` and the source header — HACS just needs the file in the repo root).

**Improved — editor *Elements* tab.** Section headers are now sorted alphabetically, each has a Material icon, and the title/description are split into a bold name + a muted subtitle, with the item count shown as a small pill badge (greyed out when the section is empty). The *Image* tab sections got the same treatment.
